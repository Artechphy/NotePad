输入为[报告Markdown](NotePad期中实验报告.md)，输出为[独立DOCX](NotePad期中实验报告.docx)。报告共7页，含6张修复候选在Android 14上的真实截图，功能与测试基线为 `d0726f6`。

## 格式

- A4，页边距上下2厘米、左右2.3厘米，页脚仅有页码。
- 正文Songti SC 12磅、18磅行距；标题使用Heiti SC，主标题18磅、一级14磅、二级12磅，均为黑色。
- 表格10.5磅，浅色表头和浅灰边框；截图保持原始比例，并提供图题及替代文本。
- 文档指定Arial和Menlo作为西文字体，捆绑渲染环境映射为Liberation Sans和Liberation Mono；中文实际渲染字体已核对为STSongti SC及STHeiti SC。

没有教师模板可供复用，以上为本次独立报告的默认格式，不宣称继承教师模板字体。没有填写姓名、学号或班级；DOCX作者及最后修改者属性为空。跨机器字体替换或复制到模板后，应重新检查分页。

## 生成与渲染

本次使用Codex依赖加载工具返回的捆绑Python、python-docx及捆绑LibreOffice，不调用用户桌面版LibreOffice。生成脚本为 `tools/docs/build_report.py`，支持报告用到的标题、表格、编号段落、代码、分页及双图标记。

在已加载依赖的环境中，使用返回的Python路径执行：

```bash
<捆绑Python路径> tools/docs/build_report.py
```

macOS捆绑渲染器默认不一定发现系统中文字体。`tools/docs/prepare_render_fonts.py` 只将本机已有字体的字节复制到指定临时目录，并创建进程级fontconfig文件，不改系统字体配置，不将字体文件加入仓库。

```bash
<捆绑Python路径> tools/docs/prepare_render_fonts.py \
  --runtime-root <依赖加载工具返回的dependencies目录> \
  --output-dir /private/tmp/notepad-report-fonts

env FONTCONFIG_FILE=/private/tmp/notepad-report-fonts/fonts.conf \
  <捆绑Python路径> <documents技能目录>/render_docx.py \
  docs/实验报告/NotePad期中实验报告.docx \
  --output_dir /private/tmp/notepad-report-render --emit_pdf
```

角括号内容是需替换的路径占位符。PDF和页面PNG用于内部排版检查，不作为本次课程报告交付物。
