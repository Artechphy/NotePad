# NotePad 项目说明

本实验在教师指定NotePad应用上完成时间戳、查询和附加功能扩展。当前以 `d0726f6` 为功能基线，使用Java/XML、原SQLite数据库及ContentProvider，没有迁移Kotlin或Room。

## 要求与功能

题目第2页要求列表时间戳、按标题或内容查询，并至少完成两项附加功能。当前实现界面美化和分类，并额外完成单篇文本导出。

### 时间戳与查询

列表显示最近修改时间，格式为 `修改于 yyyy-MM-dd HH:mm`，使用设备时区。时间为空、0或负值时显示“时间未知”。列表按 `modified DESC, _id DESC` 排序。

标题、正文或分类实际变化才更新修改时间；创建时间保留。纯查看、搜索、无改动保存和导出不会额外改写已保存笔记的时间。

查询去掉关键词两侧空白，匹配标题或正文。分类约束作用于整个OR条件：

```sql
(title LIKE ? ESCAPE '!' OR note LIKE ? ESCAPE '!') AND category = ?
```

使用参数绑定，`%`、`_` 和 `!` 按字面值转义。空关键词恢复当前分类内全部笔记，清空关键词不清除分类。列表使用CursorLoader后台查询，未实现历史提案中的250ms防抖、ViewModel或StateFlow。

### 界面和分类

列表展示标题、两行正文摘要、时间、分类和结果数量。编辑页提供标题、分类和正文输入，以及状态、完成、返回和更多菜单。空正文的摘要为“暂无正文”；空标题可由正文生成，最多40个Unicode码点。

每篇笔记使用一个分类：未分类、学习、生活、工作，稳定ID分别为 `uncategorized`、`study`、`life`、`work`。分类可持久化并与查询组合；在分类中新建会继承当前分类。“全部”仅为列表筛选状态。

### 文本导出

编辑页“更多 → 导出为文本”先保存当前内容，再打开系统文件保存界面。UTF-8文本包含标题、分类、修改时间和正文；建议名清理路径字符并保留Unicode边界。

写入在后台执行，写入和关闭成功后才报告成功。取消选择器不撤销导出前已经完成的保存。该功能不包含导入恢复、批量备份或云同步；导出入口要求API 19及以上。

## 保存与恢复

- 完成和返回均尝试保存。空新笔记点完成留页提示，直接返回清理空草稿；已有笔记清空正文后仍保留。
- 保存失败时，页面与系统返回均留在编辑页，保留三字段并显示失败。API 33及以上使用平台Back回调，较低版本使用 `onBackPressed()`。
- 后台保存失败会提示。实例状态另存未保存输入，来源暂不可读或删除后，配置重建及系统保留实例状态后的进程重建仍可恢复编辑内容。
- 失败后可选择“更多 → 另存为新笔记”，明确操作才插入新记录；依赖恢复后也可重试保存原记录。
- 撤销已有笔记恢复本次进入时的三字段，撤销新笔记清理草稿；撤销不承诺恢复旧修改时间。

编辑页删除有确认框。列表长按删除直接生效，是保留的交互差异，不能写成所有删除入口均有确认。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `NotesList` | 列表、分类、搜索、Loader及新建／列表菜单 |
| `NoteEditor` | 编辑、保存／返回、撤销、删除、恢复、粘贴与导出入口 |
| `NotePadProvider` | SQLite建表升级、CRUD、修改时间和变更通知 |
| `NotePad` | URI、MIME、表列名及排序契约 |
| `NoteSearch`、`NoteTimestamp` | 参数化查询和时间显示 |
| `NoteCategory`、`NoteText` | 分类映射、标题和摘要 |
| `NoteExport`、`NoteExportTask` | 导出格式、文件名、后台写入与反馈 |
| `TitleEditor`、`NotesLiveFolder` | 原有兼容入口 |

页面通过ContentResolver访问Provider，Provider统一访问SQLite。列表收到变更通知后按当前条件刷新，没有第二套数据仓库。

## 数据结构和升级

数据库为私有目录中的 `databases/note_pad.db`，表为 `notes`，版本为3。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `_id` | INTEGER PRIMARY KEY | 记录标识 |
| `title` | TEXT | 标题 |
| `note` | TEXT | 正文 |
| `created` | INTEGER | 创建时间，Unix毫秒 |
| `modified` | INTEGER | 修改时间，Unix毫秒 |
| `category` | TEXT NOT NULL | 分类ID，默认 `uncategorized` |

v2升级只增量加列：

```sql
ALTER TABLE notes ADD COLUMN category TEXT NOT NULL DEFAULT 'uncategorized';
```

保留旧ID、标题、正文及时间，旧笔记归未分类。未知旧版本明确失败，不删表重建。已取得隔离数据库文件和真实旧APK覆盖安装证据，未承诺所有旧版本均可升级。
