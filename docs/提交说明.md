# NotePad 提交说明

本页整理课程提交准备和项目交接材料。题目已明确功能要求，额外模板、平台、命名和截止时间仍以教师通知为准；下列是现有材料，不表示题目强制全部提交。

## 提交前核对

- 确认两项必做及至少两项附加功能可展示；当前有界面美化、分类和导出三项。
- 在实际交付设备安装、打开并演示，不外推API 34模拟器结论。
- 使用真实运行截图，不将设计图当运行截图。按模板补本人资料时，仅填写用户确认的内容。
- 保留37项警告、10个未覆盖分支和未完成人工验收的事实，不写成“所有测试均通过”。
- 如需源码包，保留Wrapper、源码、测试和文档；排除 `.gradle/`、构建／IDE缓存、`local.properties`、签名私钥和凭据。
- 覆盖安装须相同包名和签名；不能卸载后冒充升级验证。

## 文档格式与维护

当前DOCX采用A4及统一中文字体，没有套用尚未提供的教师模板，未填写姓名、学号、班级。正文和真实截图可复制到教师指定模板；模板只读保留，另存新文件。

生成源为 `tools/docs/build_report.py`，输入为报告Markdown。本次使用Codex捆绑Python和LibreOffice渲染，具体格式与检查见[报告生成说明](实验报告/生成说明.md)。
