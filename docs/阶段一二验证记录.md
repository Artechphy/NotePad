## 失败与修正记录

1. 原始命令因 JAVA_HOME 无效失败；临时指定现有 JDK 后可运行。
2. 离线基线构建因 AAPT2 缓存缺失失败；经指定代理补全后构建成功。
3. 新增测试最初因 AndroidX 标记、测试依赖未缓存和测试清单最低 SDK 冲突而未执行；补充测试配置与依赖后进入测试执行，未提高应用 minSdk。
4. 第一轮列表组件测试 20 项中 1 项失败：LEGACY 调度器立即在游标通知回调内执行重查，触发 ConcurrentModificationException。将测试调度器暂停并显式推进队列，按异步顺序执行；保留原断言，复测通过。产品代码未为迁就该测试改动。
5. 临时模拟器先后尝试 SwiftShader、宿主图形关闭 Vulkan、关闭加速配置，均出现 QEMU CPU/main loop 挂起并以 139 退出。未使用或清空用户已有 AVD 数据，未产生实际运行截图。

## 复现入口

在含 `settings.gradle` 的 `NotePad/` 目录操作：

```bash
env JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home \
  ANDROID_HOME=/Users/artechphy/Library/Android/sdk \
  bash ./gradlew --offline :app:assembleDebug

env JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home \
  ANDROID_HOME=/Users/artechphy/Library/Android/sdk \
  bash ./gradlew --offline :app:testDebugUnitTest
```

以上路径针对本机；其他设备按安装位置设置 JDK 和 SDK。首次运行若缺依赖，移除 `--offline`，在同一条 Gradle 命令中添加：

```text
-Dhttp.proxyHost=127.0.0.1 -Dhttp.proxyPort=65533
-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=65533
-Dhttp.nonProxyHosts=localhost|127.*
```

shell 中最后一项应用单引号包裹，避免 `|` 被解析为管道。Robolectric API 34 的 Android 测试运行时本机已缓存；新机器首次解析该运行时也须沿指定代理配置测试 JVM，不能将 Gradle 离线模式理解为运行时依赖已经齐全。

产物：`app/build/outputs/apk/debug/app-debug.apk`。

测试报告：`app/build/reports/tests/testDebugUnitTest/index.html`。
